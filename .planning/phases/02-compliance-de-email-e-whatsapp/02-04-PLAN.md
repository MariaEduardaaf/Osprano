<objective>
Trocar o gate de WhatsApp de "estágio de Kanban arrastável" para "opt-in registrado do prospect" (COMP-04). Depende do plano 02-01 (campos `waOptInAt`/`waOptInSource`, literal `wa_opt_in`, helper `hasWaOptIn`). Este plano: (1) adiciona `leads.recordWaOptIn` (grava campos + evento); (2) `whatsapp.sendFollowup` passa a exigir `lead.waOptInAt` via `hasWaOptIn`, removendo o check por `stage`, e corrige a docstring desatualizada; (3) a UI `WhatsAppFollowup` ganha um fluxo mínimo "Registrar opt-in" (origem + confirmar) que precede o envio, com a prop `optInAt` vinda do CRM; (4) o CRM deixa de esconder o bloco WhatsApp por estágio — o wrapper em `crm/page.tsx` (único ponto de render do componente no app) passa a depender só de `lead.phone`, senão arrastar o card continuaria pré-requisito de fato.

Purpose: Um vendedor não consegue mais destravar WhatsApp a frio movendo um card — exige um registro real, atribuível, de consentimento. E um lead COM opt-in em qualquer estágio alcança a UI de envio.
Output: recordWaOptIn + gate por opt-in + UI de registro + render sem gate de estágio.
</objective>

    ```ts
    /** Registra o opt-in explícito do prospect para WhatsApp (COMP-04). Origem + timestamp. */
    export const recordWaOptIn = mutation({
      args: {
        leadId: v.id("leads"),
        source: v.string(), // "replied_email" | "phone_call" | "in_person"
        note: v.optional(v.string()),
      },
      handler: async (ctx, { leadId, source, note }) => {
        const orgId = await requireOrgId(ctx);
        const lead = await ctx.db.get(leadId);
        if (!lead || lead.orgId !== orgId) throw new Error("Lead não encontrado");
        const now = Date.now();
        await ctx.db.patch(leadId, { waOptInAt: now, waOptInSource: source });
        await ctx.db.insert("events", {
          orgId,
          type: "wa_opt_in",
          leadId,
          at: now,
          meta: { source, ...(note ? { note } : {}) },
        });
        return { optInAt: now };
      },
    });
    ```
    (`mutation`, `v`, `requireOrgId` já estão importados no arquivo.)
